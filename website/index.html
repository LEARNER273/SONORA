Musical mobile app — guitar, piano, bass, synth, drums

How to use

  1. Download the app. Open the SONORA repository on GitHub and download the file SONORA-debug.apk.
  2. Install it on your phone. Open the APK from your file manager and tap Install.
  3. Open SONORA. Find SONORA in your app list and open it — you're ready to play.

The app works offline — you don't need the internet to use it. If your phone refuses the install, allow installing apps from your browser or file manager in Settings.
